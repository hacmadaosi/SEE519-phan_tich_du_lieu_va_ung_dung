# Tạo venv trên Windows

## Di chuyển vào thư mục chứa dự án

```cmd
cd root/SEE519
```

## Tạo virtual environment

```cmd
python -m venv .venv
```

# Kích hoạt venv

Windows (CMD):

```cmd
.\venv\Scripts\activate
```

# Cài đặt các dependencies cần thiết

```cmd
pip install -r requirements.txt
```
